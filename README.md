# School Website Project

A simple responsive school website created using HTML, CSS, and JavaScript in a single HTML file.

This project was generated using the exact prompt below without any modifications.

---

# Prompt Used

```text

Create  a simple responsive school website using HTML, CSS and js.

Requirements:

1. WEBSITE SHOULD HAVE FOLLOWING SECTIONS:

- header with school name("School of AI and Emerging Technologies") and navigation menu(home, about, courses, contact)
- home section with a welcome message and banner image (use online suitable images whenever required)
- about section describing school
- courses section listing atleaset 3 courses
- contact section with a form(name, email , message) 

2. use clean and beginner friendly  html structure.

3. add basic css styling 
- use simple color theme(blue/white or similar) with gradient
- make layout responsive for mobile screens
- add hover effects on butons and navigation links


4. use js to 
- validate the contact form(check empty fields abd valid email)
- show an alert message on successful form submission
- add a simple interactive feature (like a button that displayes "Welcome to our School")


5. keep code well commented so beginner can understand

6. write everything in a single html file (internal css and js)

7. ensure the design is simple , clean and suitable for a school project.

output:
- complete working code in one file

```
